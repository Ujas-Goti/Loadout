# Loadout

CS 351 Project 1. Client-side React store for gaming mice, keyboards, headsets, mousepads, and controllers.

## Run locally

```bash
npm install
npm run dev
```

## Build for Google Cloud (static)

```bash
npm run build
```

Upload the files inside `dist/` to the Cloud Storage bucket. Do not upload `node_modules`.

## Files

- `src/data/products.json` — 25 products, same schema
- `src/css/store.css` — custom CSS (Bootstrap 5 is a dependency)
- `src/js/utils.js` — cart helpers
- `public/images/` — product photos from Unsplash
